# Manuscript and package scope

Reference: ML-Driven Material Design and Multiscale Analysis of Large-Scale RC Structures: A Performance-Based UHPC Local Enhancement Approach

Manuscript basis: research/Sensi924.docx, SHA-256 257d307377e78ed83d79d9419981738da79f603fa4424adcf318e9f7622300ae. The separate Sensi924_review_copy.docx has the same title but different contents; this package uses research/Sensi924.docx. Manuscript files, presentation decks and build caches are outside this data/code deliverable.

The original external model directory was discovered through the literal data path in train_and_evaluate.py. Its mesh and scripts are preserved as supporting original material. Their correspondence to the 10-story hospital model, DDM analysis, NSM coupling and zero-DOF FMC implementation described in the manuscript has not been established. This package does not claim complete reproduction of those analyses.

No model weights/checkpoints, hospital-scale NSM/DDM solver sources, earthquake excitation record, complete global time histories or definitive figure-to-script mapping were identified in the two source directories. These should be added if the reviewers require full-paper reproduction.
