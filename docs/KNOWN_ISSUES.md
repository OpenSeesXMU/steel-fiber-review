# Issues requiring author reconciliation

1. In train_and_evaluate.py, the six input columns are [fiber type, df, fu, Le, fc, theta], but f_c = X_raw[:, 5] selects theta instead of fc (column 4). The original and portable copies retain this expression. Correcting it changes model features/results and requires a new, explicitly documented scientific revision.
2. The 90/10 evaluator fits both MinMaxScaler instances before splitting the dataset; test observations therefore influence scaling. Preserve this when reproducing the existing result, and reconsider it for an independently assessed model.
3. Sensi924 specifies a 10% held-out set. train_and_evaluate.py uses that split (54 train/7 test for 61 samples), while RF, XGBoost, hybrid, ultimate and neural alternatives use 20% (48/13). Alternatives are included as existing versions, not presented as the published final method.
4. train_and_evaluate.py defines the residual anchor as the last five force points and applies a correction to the last 20% of the curve; other versions use the final force point and different synthesis rules.
5. triple_curve_compassion.py obtains an approximately 31.8 N peak from pi*0.2*6.5*7.8 and an analytical curve. It does not call the trained ML model. predict_curve.py and predict_scifiber_curve.py are likewise analytical generators. The claimed database-trained forward prediction needs a confirmed training-to-inference implementation.
6. simulate.py generates a synthetic database. Its ablation result is not evidence of ablation on the supplied 61 experimental curves. batch_generate_materials.py uses a hand-written surrogate curve function. Both are retained and explicitly described as demonstrations.
7. The archived simulation main.tcl sources fibers.tcl before concrete nodes are defined, and uses conventional truss/equalDOF fiber construction. This differs from the manuscript zero-DOF FMC description. It also sources a file defining a static subdivision procedure rather than executing the reported earthquake time-history workflow. Full simulation execution has not been validated.
8. Original sources contain local absolute paths and dependence on the working directory. Use the review runner and portable copies for supported tasks. Original sources are retained for provenance.
9. Curve origin/digitization and source references require author confirmation. Additional raw curves without parameter records are archived separately and are not inserted into the final database.
10. Archived PNGs and partial simulation output are existing artifacts; their correspondence to specific submitted figures has not been confirmed. Newly reproduced outputs are stored separately.
11. The parameter workbook contains 62 populated records but the final database contains 61. The record yoo2017_S13_B.csv lacks an exact-name raw curve and is absent from the final database. It is reported and excluded during rebuilding. The differently named yoo2017_S13_BA.csv is retained in the raw archive without being treated as the missing record.
