# Packaging exclusions

Presentation slides/templates, manuscript DOCX files, generated document/slide render caches, Git history, Python environments, temporary files, screenshots used for presentation design, software executables and training logs are outside this source/data package. All experimental CSV curves found in the two relevant csv trees, supplemental parameter CSVs, original Python scripts, the available model Tcl/mesh inputs and relevant existing result figures are included. Path.txt and time.txt are local run bookkeeping. Archive checksums are in manifest_sha256.csv.
